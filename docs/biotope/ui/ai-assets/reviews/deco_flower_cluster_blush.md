## UI Seed Fit

The low horizontal ranunculus-like sprig supplies the requested blush variation
while keeping realistic petals, pale leaves, ivory porcelain, and restrained
champagne-brass mechanics. It feels airy rather than bouquet-heavy.

## Background Mode

Correct. The final is a 1536 x 1024 `Format32bppArgb` PNG with four transparent
corners. The audit found 1,358,603 transparent pixels, 7,403 partial edge
pixels, 206,858 opaque pixels, zero blue-fringe pixels, and inset bounds of
`(175, 239)` to `(1360, 808)`.

## Slightly Off

is visually distinct from the white cluster.

## Flutter Usage

Use as a subtle blush variation along a card edge or inside a quiet summary
panel.
