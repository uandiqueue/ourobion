## UI Seed Fit

The pale realistic leaf is the clear primary form, supported by a short stem,
miniature bud, ivory collar, and softly polished brass sensor node. The result
is quiet, precise, and useful as metadata-row punctuation.

## Background Mode

Correct. The final is a 1608 x 978 `Format32bppArgb` PNG with four transparent
corners. The audit found 1,325,656 transparent pixels, 3,353 partial edge
pixels, 243,615 opaque pixels, zero blue-fringe pixels, and inset bounds of
`(185, 227)` to `(1379, 728)`.

## Slightly Off

The brass node is intentionally simple and more geometric than the leaf, but
the leaf remains dominant and prevents the motif from reading as jewelry or an
industrial component.

## Flutter Usage

Use as a small decorative node for dividers and metadata rows.
