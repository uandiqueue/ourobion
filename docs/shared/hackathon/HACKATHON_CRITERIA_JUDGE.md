## Pillar 1 — Problem — Score: 4/5

No simpler alternative (recursive SQL / in-memory traversal) is named and dismissed. The two-tier-truth framing ("Neo4j is a cheap-to-drop projection") explains *governance*, not *why a graph DB at all* for this size.

The docs call this a property that "can't be prompted away," which overstates it. Honest framing would be "enforced conditional on an honest flag + distinct populated sources."

## Pillar 3 — Evidence — Score: 4/5

**One-line verdict:** The evidence design is genuinely baseline-driven and well-aligned to the claims — the correct single-call baseline is baked into the thesis, gating is deterministic and unit-testable, and cost is logged from day one — but it stops exactly at the statistical-honesty line that separates a 4 from a 5, and its ground-truth foundation (≈40–60 self-labelled edges) is thin for a health-science task.

**Score rationale (tied to the anchors):**
The design clears anchor-4's bar — *"every claim traces to evidence, compared against a sensible baseline, including the simple one."* This is not aspirational: the baseline it names (`docs/HACKATHON_DIRECTION.md` §7 and §6-Pillar-3) is the single-LLM "does this look right?" re-ask, which is *precisely* the agentic-track's "comparison against the single-call baseline." Pre-registered success criteria (§7 bullet 1), cost/latency logging from commit #1, and a planned ablation (synthesis+`quoteCheck` only vs. +verifier) are all present. Critically, **Claim 2a is essentially airtight**: I verified in `shared/brain/relationships.schema.ts` (the `superRefine` invariant: `supported`/`contradicted` requires `independentRetrieval.performed === true`) and `shared/brain/index.ts` (`edgeScore`/`servingBand`/`SERVABLE_VERDICTS`) that "ungrounded ⇒ not served" is a pure, testable code property, not an assertion. That is real, reproducible evidence.

It is **not a 5** because §7 contains zero provision for the things anchor-5 demands — sample size justification, variance/confidence intervals, and edge cases. The gold set is ~40–60 edges spread across four failure modes (≈10–15 each, split further into positives/negatives), so any "verifier caught 8/10 vs. baseline 2/10" headline would carry enormous, unreported uncertainty. The ground-truth quality question the rubric weights hardest ("was this edge *actually* bad?") is unaddressed: no second annotator, no inter-rater agreement, no named domain expert, no blinding or independent construction of the set described. That combination — real baseline, but small/possibly-selection-biased samples with no statistical treatment — is the textbook boundary between 4 and 5, so it lands at 4, not above.

**Strongest evidence / what works:**
- The **right baseline is the thesis, not a bolt-on**. The claim ("decorrelated + independent-retrieval verifier beats a same-model rubber-stamp") is defined *as* a baseline comparison. That is the single most rubric-aligned decision in the submission.
- **Deterministic gating = provable Claim 2a.** `edgeScore`/`servingBand` are pure functions and the grounding invariant is schema-enforced (`relationships.schema.ts`), so "refuses ungrounded edges" is demonstrable by unit test, not demo.
- **Honest, real instrumentation history:** the 1,200-paper run is corroborated by the session log (`docs/sessions/20260703T065307Z-…`), and the CORE rate-limit self-correction (fabricated "1000/day" assumption → driven to a real 429 → corrected to the measured `10/60s` bucket) is a bona-fide "beat your own baseline assumption with evidence" story.
- Public held-out benchmarks (SciFact/HealthVer/BioRED, `BRAIN-MODELS-TRAINING.md`) are real, correctly-sourced splits with observed schemas.

**Weaknesses & what would raise the score (concrete):**
1. **Ground-truth rigor is the biggest gap.** A ~50-edge gold set labelled by a 1–3-person student team, with no inter-annotator agreement (κ), no adjudication, no domain-expert check, and no described blinding, is a fragile foundation for "this edge was genuinely a direction-flip / correlation-as-causation." Fix: ≥2 independent annotators, report agreement, adjudicate disagreements, and have the labeller blind to which arm produced the edge.
2. **Sample size + no variance.** ~10–15 edges per failure mode cannot support a significance claim. Add bootstrap CIs on the catch-rate delta, expand to ~150–200 edges, and state the minimum detectable effect. Without this it cannot reach 5.
3. **Selection/construction bias risk.** If the gold set is simply "edges the synthesis LLM happened to emit, then hand-picked," it measures only this model's error distribution and risks being the "cherry-picked demo runs as an eval" red flag. Fix: construct a balanced, pre-specified set of curated/injected failure modes independent of pipeline output.
4. **The ablation bundles three variables.** "Adversarial + independent-retrieval + decorrelated-family" is tested as one treatment against one baseline. That cannot attribute the win to decorrelation vs. independent retrieval vs. adversarial prompting.
