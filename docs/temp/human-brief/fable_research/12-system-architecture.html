Reading it: follow blue down the left = the serve pipeline (user data → report). At S7 the red loop branches right (gaps), runs across the top row, drops at A6, returns along the bottom row to S6, and the thick red arrow carries new relationships back up into S7 — the cycle. Two green starts feed the loop without being in it (prepopulation seed → retrieval A3; registry bootstrap → gap ledger A1). Not drawn to keep it clean: U1 applicability (an LLM feeder cached into S7) and the "held / not served" terminal off S6 — both noted in 12-system-architecture.md.

The red loop is the offline authoring factory (ingest CLI / prepopulation terminal); the blue spine runs on the app backend and only reads what the loop produced, so the user never waits for it. Node accent = highest-cost compute; corner dot = the model. Full per-stage schemas, §8 models, §9 hyperparameters in 12-system-architecture.md.
